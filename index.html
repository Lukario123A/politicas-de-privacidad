Política de Privacidad

Aplicación Xalculator

Esta Política de Privacidad aplica a la aplicación Xalculator, desarrollada por Luis Vergara.

Si tienes preguntas sobre esta política, puedes escribir a: uvanlost@gmail.com

Importante: Esta aplicación no recopila información personal identificable.

1. Información que recopilamos

La aplicación no recopila información personal identificable como:

  • Nombre
  • Correo electrónico
  • Dirección
  • Número de teléfono

2. Datos técnicos

Podemos recopilar automáticamente datos técnicos básicos como:

  • Tipo de dispositivo
  • Versión del sistema operativo
  • Registros de errores (crash logs)

3. Uso de la información

La información técnica se utiliza únicamente para:

  • Mantener la aplicación funcionando correctamente
  • Corregir errores
  • Mejorar la experiencia del usuario

4. Compartición de datos

Esta aplicación no comparte información personal con terceros.

5. Publicidad

La aplicación puede mostrar anuncios mediante servicios como Google AdMob. Estos servicios pueden recopilar identificadores anónimos para mostrar publicidad relevante.

6. Cambios en esta política

Podemos actualizar esta política en el futuro. La versión publicada en esta página será la vigente.

7. Contacto

Para cualquier duda sobre esta política: uvanlost@gmail.com
